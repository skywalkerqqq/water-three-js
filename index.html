操作指南

按 H 或点击面板外空白处关闭

🖱 鼠标

  • 左键拖拽 — 旋转视角
  • 滚轮 — 缩放
  • 右键拖拽 — 平移 / 下潜到水下
  • 双击海面 — 丢入球（Shift = 方块）
  • 拖拽物体 — 移动 / 松手甩出

⌨ 键盘

  • B 进入 / 退出堆沙堡模式
  • C 蹲下来看沙堡
  • Space 暂停时间
  • Ctrl+Z 撤销
  • H 显示 / 隐藏本指南

🏖 堆沙堡工具

  • 堆沙 / 挖沙 — 左键拖拽堆高或挖低
  • 压平 — 抹平笔刷区域
  • 塔台 — 堆一座圆塔
  • 沙桶倒沙 — 点一下倒出小塔（可叠高）
  • 移动沙堡 — 拖动小塔搬家
  • 打湿 / 吹干 — 湿沙更结实不易塌
  • 插旗 — 在沙滩插一面小旗
