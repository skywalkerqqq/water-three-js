## 📖 项目简介

WaterThreeJS 是一个实时 WebGL 场景：一片在水面之上与水面之下都像「真水」的频谱海洋，环绕着一座程序化生成的沙岛，你可以在上面堆沙堡。画面里的一切都是解析着色器运算或生成式几何 —— 没有图片文件、没有环境贴图、没有需要下载的素材。

这里的沙子是真正的模拟，而不是装饰：每个沙格都带一个「含水量」，干沙会向休止角坍塌，湿沙能近乎垂直地立住，而潮水冲刷会慢慢把沙堡吃掉。

## ✨ 功能特性

### 🌊 海面
- **频谱 Gerstner 波场**跑在**极坐标 LOD 网格**上 —— 从长涌浪到细碎波纹几十个波叠加，按深水色散关系（`ω = √(g·k)`）生成，长波比短波跑得快。
- **屏幕空间反射**：反射光线在「水体之前的颜色/深度缓冲」里步进，小岛与水面之上的一切都会倒映在海面。
- **两层细节法线**按屏幕空间光线微分淡出，让涟漪一路延伸到地平线而不产生闪烁锯齿。
- 物理化着色：Schlick **菲涅尔**、**Beer–Lambert** 折射、逆光浪尖的**次表面散射**、GGX **太阳高光**（带高光抗锯齿）与**分层泡沫**。

### 🏝️ 海岸、岛屿与沙子模拟
- 一座沙**岛高度场**从海床抬升、穿过水线、直到干沙沙丘，干沙/湿沙在海滩上自然过渡。
- **含水量驱动的热力坍塌**：干沙向约 32° 的休止角滑塌，湿沙能保持近乎垂直的立面；海水冲刷湿沙比干沙更慢。
- **可交互的沙堡建造**：沙桶倒沙成塔、堆沙/挖沙/压平/打湿/吹干笔刷、带垛口的实例化塔楼、存读档与撤销。
- 世界空间的**泡沫与湿度场**会在碎浪后平流泡沫，并在潮水扫过处留下逐渐变干的湿痕。

### 🌴 生机与氛围
- 高挑的**椰子树**：羽状下垂的复叶、椰子果、还有几片泛黄的枯叶；树冠会随海况摇摆。
- **海鸥**沿倾斜椭圆轨道盘旋，滩上散落**扇贝壳**，可插下随风飘动的**小旗**。
- **程序化音效**（WebAudio，零文件）：海浪随浪组呼吸，风声随风暴增强。
- **体积云**：半分辨率光线步进 + 时间重投影、自阴影与逆光银边 —— 同一片云还会在海上投下漂移的阴影。

### 🎬 渲染管线
- HDR（半浮点）渲染，独立的折射通道与深度纹理，渲染目标开启 **MSAA**，渲染分辨率按设备像素自适应。
- 后期：阈值**辉光**、水下**体积光**、**ACES** 电影级色调映射、胶片颗粒、色差与暗角。
- 六个一键**电影级预设** —— *热带正午、黄金时刻、绯红日落、蓝调时刻、清晨破晓、风暴之海*。
- **水下**：斯涅尔窗、体积光束、海床焦散与海雪粒子。

## 🚀 快速开始

**环境要求：** Node.js 18+，以及支持 WebGL2 的浏览器（Chrome、Edge、Firefox、Safari）。场景面向桌面级显卡。

```bash
# 安装依赖
npm install

# 启动开发服务器（自动打开 http://localhost:5173）
npm run dev
```

生产构建：

```bash
npm run build      # 输出到 dist/
npm run preview    # 本地预览生产构建
```

Windows 用户也可以直接双击 **`start-dev.bat`**，首次运行会自动安装依赖并启动开发服务器。

## 🧠 实现原理

全部基于 **WebGL2 + GLSL**，通过 Three.js 运行。没有 WebGPU、没有计算着色器、也没有 FFT —— 海洋是纯解析着色器数学，这也是它能在任意浏览器里零素材跑起来的原因。

### 渲染管线

每帧是一串写入**半浮点（HDR）**目标的渲染通道，只在最后统一做一次色调映射：

1. **折射通道** —— 天空 + 海床 + 小岛（水面之下的一切）写入带深度纹理的 HDR 目标。
2. **场景通道** —— 包含水面的完整场景；水体着色器读取上一步的折射颜色/深度。
3. **体积云** —— 低分辨率光线步进，在色调映射前合成进 HDR 缓冲。
4. **后期** —— 水下吸收 + 体积光、阈值辉光、ACES 色调映射与 sRGB 编码。

### 海浪

海面是逐顶点求和的 **Gerstner** 波场，网格为**极坐标 LOD 网格**（同心环半径按几何级数增长，使每个格子始终约为视距的 3–4%：相机脚下约 0.4 m，地平线处约 150 m）。谐波表在 CPU 端按**双峰 JONSWAP 频谱**生成 —— 一个涌浪峰 + 一个由风速决定的风浪峰 —— 再供顶点着色器、海滩/海床着色器**以及** CPU 浮力解算共同使用。

同一次求和还顺带得到**解析海面法线**与水平位移的**雅可比行列式**：当雅可比为负，说明海面正在挤压 —— 也就是碎浪 —— 而这正是泡沫被播撒的地方。

### 水体着色

- **Beer–Lambert** 透射率（`exp(-ABSORB/clarity · 厚度)`）给出从青绿到深蓝的渐变，折射的海床从中透出。
- **Schlick 菲涅尔**在掠射角把折射过渡到反射；**GGX** 太阳高光随距离变宽，并依据屏幕空间法线方差做抗锯齿。
- 反射走**屏幕空间**光线步进，未命中时回退到共享的解析大气函数，让倒映的地平线始终与真实天空一致。

### 沙堡模拟

海滩是一张 512² 的雕塑高度场（约 1 m 一格），用脏矩形上传更新纹理。每格带一个**含水量**，驱动热力坍塌步：干沙向休止角松弛并滑塌，湿沙粘住、能立出近乎垂直的坡面。海水会侵蚀潮水带内的沙，干沙被吃得更快。带垛口的塔楼是坐在高度场上的实例化道具，共享的 `heightAt()` 让「看到的、浮力算的、侵蚀吃的」三者保持一致。

### 体积云

在一个跟随相机的高空平板里做真正的光线步进，半分辨率渲染并用时间重投影清理。每个采样点的光照用短步长指数光行进来做自阴影、用 Beer–Powder 处理薄边、用 3 个八度的多重散射近似，并用双瓣 Henyey–Greenstein 相位做出逆光银边。

## 🏗️ 项目结构

```
index.html            启动屏、HUD、画布
src/
  main.js             渲染器、相机、控制器、渲染通道、浸没判定
  Sky.js              锁定相机的大气穹顶
  Ocean.js            Gerstner 海面网格 + 完整水体着色器（含 CPU 高度函数）
  Floor.js            带沙丘的海床 + 动态焦散
  Island.js           沙岛高度场：海滩、干湿沙、焦散、雕塑
  FoamField.js        世界空间泡沫与湿度场（平流、跟随相机的 clipmap）
  FloatingBodies.js   漂浮物的浮力：上下浮动、倾斜、地形碰撞
  Sandcastles.js      实例化塔楼：倒沙、叠高、倾斜、坍塌、被冲走
  Bucket.js           玩具沙桶道具 —— 翻转倒出成形沙堆
  PalmTrees.js        实例化椰子树 —— 弯曲树干 + 下垂、随风摇摆的树冠
  Birds.js            程序化海鸥，倾斜椭圆轨道
  Audio.js            WebAudio 海浪 + 风声，随海况变化（无音频文件）
  Clouds.js           体积云 —— 盒体受限光线步进，低分辨率
  Post.js             水下体积光 + 云合成 + 辉光 + ACES
  Particles.js        海雪点场
  shaders/common.js   共享 GLSL：噪声、大气、Gerstner、焦散、染色
```

所有输出均为**线性 HDR**；色调映射只在最终合成时做一次，因此反射、折射与辉光的能量始终保持一致。

## 📋 环境要求

- 支持 **WebGL2** 的浏览器（Chrome、Edge、Firefox、Safari）。
- 建议使用桌面级显卡。较轻量的硬件上，可调低 `src/Ocean.js` 里的海浪网格分辨率，以及 `src/Post.js` 里的体积光步进数。
